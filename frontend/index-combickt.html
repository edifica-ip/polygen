Combinational Circuits Explorer

Digital Electronics • Polygen Learning Module

A combinational circuit is a digital circuit whose output depends only on the present combination of inputs. These circuits do not store previous states and form the foundation of arithmetic units, data selectors, code converters, encoders, decoders and comparators.

Adders

Perform binary addition operations.

  • Half Adder
  • Full Adder
  • Parallel Adder
  • Ripple Carry Adder
  • Carry Look-Ahead Adder
  • BCD Adder

Subtractors

Perform binary subtraction operations.

  • Half Subtractor
  • Full Subtractor

Multiplexers

Select one input from multiple inputs.

  • 2 : 1 MUX
  • 4 : 1 MUX
  • 8 : 1 MUX
  • 16 : 1 MUX

Demultiplexers

Route one input to multiple outputs.

  • 1 : 2 DEMUX
  • 1 : 4 DEMUX
  • 1 : 8 DEMUX

Encoders

Convert active inputs into binary codes.

  • Encoder
  • Priority Encoder

Decoders

Convert binary codes into output lines.

  • 2 : 4 Decoder
  • 3 : 8 Decoder
  • BCD to 7-Segment

Comparators

Compare binary numbers.

  • A > B
  • A < B
  • A = B

Code Converters

Convert between different digital codes.

  • Binary ↔ Gray
  • Gray ↔ Binary
  • BCD ↔ Excess-3

Key Characteristics:
  • No memory elements
  • No feedback path
  • Output depends only on present inputs
  • Built using logic gates
  • Used extensively in arithmetic and decision-making circuits
