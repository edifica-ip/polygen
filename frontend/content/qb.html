QBASIC Reference — Statements • Functions • Syntax • Examples

This reference covers commonly used QBASIC commands, statements, functions, loops, arrays, graphics, and file handling concepts. Each section contains a description, syntax, and a short example.

PRINT — Display Output

Description: Displays text, numbers, and expressions on the screen.

Syntax: PRINT expression

Example:

CLS

PRINT "Welcome to Polygen"
PRINT 10 + 20

END

INPUT — Accept User Input

Description: Reads data entered by the user.

Syntax: INPUT variable

Example:

CLS

INPUT "Enter your name: ", N$

PRINT "Hello "; N$

END

LET — Assign Values

Description: Assigns a value to a variable. LET is optional.

Syntax: LET variable = value

Example:

LET A = 10
B = 20

PRINT A + B

END

IF...THEN...ELSE — Decision Making

Description: Executes statements based on a condition.

Syntax:

IF condition THEN
   statements
ELSE
   statements
END IF

Example:

INPUT "Enter Marks: ", M

IF M >= 40 THEN
   PRINT "Pass"
ELSE
   PRINT "Fail"
END IF

END

FOR...NEXT — Looping

Description: Repeats statements a fixed number of times.

Syntax:

FOR variable = start TO end
   statements
NEXT variable

Example:

FOR I = 1 TO 5
   PRINT I
NEXT I

END

WHILE...WEND — Conditional Loop

Description: Repeats statements while a condition remains true.

Syntax:

WHILE condition
   statements
WEND

Example:

I = 1

WHILE I <= 5
   PRINT I
   I = I + 1
WEND

END

SELECT CASE — Multiple Conditions

Description: Tests a variable against multiple values.

Syntax:

SELECT CASE variable
CASE value1
   statements
CASE value2
   statements
CASE ELSE
   statements
END SELECT

Example:

INPUT "Enter Grade: ", G$

SELECT CASE G$
CASE "A"
   PRINT "Excellent"
CASE "B"
   PRINT "Good"
CASE ELSE
   PRINT "Try Again"
END SELECT

END

Arrays

Description: Stores multiple values using a single variable name.

Syntax: DIM array(size)

Example:

DIM A(5)

FOR I = 1 TO 5
   INPUT A(I)
NEXT I

FOR I = 1 TO 5
   PRINT A(I)
NEXT I

END

String Functions

Description: Manipulate text and characters.

Common Functions:

  • LEN() – Length of string
  • LEFT$() – Left characters
  • RIGHT$() – Right characters
  • MID$() – Extract substring
  • UCASE$() – Convert to uppercase
  • LCASE$() – Convert to lowercase

Example:

S$ = "Polygen"

PRINT LEN(S$)
PRINT LEFT$(S$, 4)
PRINT RIGHT$(S$, 3)

END

Numeric Functions

Description: Perform mathematical operations.

Common Functions:

  • ABS()
  • SQR()
  • INT()
  • RND
  • SIN()
  • COS()
  • TAN()

Example:

PRINT ABS(-10)
PRINT SQR(25)
PRINT INT(5.8)

END

Subprograms (SUB)

Description: Reusable blocks of code.

Syntax:

DECLARE SUB Display()

CALL Display

SUB Display
   PRINT "Hello"
END SUB

Example:

DECLARE SUB Welcome()

CALL Welcome

SUB Welcome
   PRINT "Welcome to QBASIC"
END SUB

Functions (FUNCTION)

Description: Returns a value to the calling program.

Syntax:

FUNCTION Add(A, B)
   Add = A + B
END FUNCTION

Example:

DECLARE FUNCTION Add(A, B)

PRINT Add(10, 20)

FUNCTION Add(A, B)
   Add = A + B
END FUNCTION

DATA, READ and RESTORE

Description: Store and retrieve constant values.

Syntax:

DATA values
READ variable
RESTORE

Example:

DATA 10,20,30

READ A, B, C

PRINT A, B, C

END

Graphics Commands

Description: Create graphics and drawings.

Common Commands:

  • SCREEN
  • PSET
  • LINE
  • CIRCLE
  • PAINT
  • DRAW

Example:

SCREEN 12

LINE (100,100)-(300,100), 4
CIRCLE (200,200), 50, 2

END

File Handling

Description: Read and write data to files.

Common Commands:

  • OPEN
  • INPUT #
  • PRINT #
  • CLOSE

Example:

OPEN "data.txt" FOR OUTPUT AS #1

PRINT #1, "Hello"

CLOSE #1

END

Common Built-in Functions

String Functions: LEN(), LEFT$(), RIGHT$(), MID$(), INSTR(), UCASE$(), LCASE$()

Math Functions: ABS(), SQR(), INT(), FIX(), SIN(), COS(), TAN(), LOG(), EXP()

Date & Time: DATE$, TIME$

Random Numbers: RND, RANDOMIZE TIMER

Program Control Statements

Common Statements:

  • CLS — Clear screen
  • END — End program
  • GOTO — Jump to label
  • GOSUB — Call subroutine
  • RETURN — Return from subroutine
  • STOP — Pause execution

Example:

CLS

PRINT "Start"

END
